From project manual to submittal register

A Claude skill that reads a construction specification, finds every submittal requirement, and builds an Excel register your team can track from day one.

Download the skill (.zip) View on GitHub How to verify the output

How it works

1A script reads the structureIt indexes the manual's sections, finds each submittals article, and splits it into items with the spec section, paragraph and page.
2Claude applies judgmentIt reads the Division 01 rules, adds closeout and administrative items, merges related ones, and flags anything it is unsure about.
3You get a workbookRegister, project rules, review queue and section summary, with date formulas that update when you enter install dates.

What it does not do

  • It does not read scanned PDFs. It needs a text layer.
  • It runs one file at a time. A manual split into volumes needs each volume, and the tool lists every section it could not find.
  • Submittals written as sentences inside construction paragraphs come through as review rows, not finished rows.

Check the work. The skill flags what it is unsure about in a Review Queue, but a person should confirm those rows and spot-check pages against the manual before the register is issued.

Try it

  • Download the zip and unzip it, or copy the submittal-register folder from GitHub, into your Claude skills.
  • Attach a project manual PDF and ask for a submittal register.
  • Optionally give install dates by spec section so required submit dates calculate.
